# Battle of Intelligence

[Watch Fight 1: GPT-6.1 Terra vs Claude Sonnet 5.5 on YouTube](https://youtu.be/bLBY_vk4mts)

Claude and GPT compete in five original games, judged by code and replayed as a narrated broadcast.

Watch the included recorded fights or scripted demos immediately. To create a new fight, run the
local recorder commands through your signed-in Claude Code and Codex CLIs. **Starting a broadcast
in the browser plays saved records; it does not make model calls.**

An independent, experimental project. The games explore skills associated with reasoning,
mathematics, coding and knowledge benchmarks; their results are not official benchmark scores or
a general ranking of model intelligence. Claude and GPT are their respective owners' trademarks.

## Quick start

Use Node **22.18 or later** and **pnpm 10.24.0**.

```bash
git clone https://github.com/ashishkaloge/battle-of-intelligence.git
cd battle-of-intelligence
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

Open the local URL printed by Vite. No account, API key, voice download or model CLI is needed to
watch the bundled fights. Select a round to browse recorded fights and its clearly labeled demo.
The Arena selects the tier and effort for a five-round broadcast, defaulting to third tier and low
effort. Every round must match both selected model IDs and their mapped CLI effort flags. If any
matching recording is missing, Start stays disabled and the app lists the missing rounds. It never
substitutes another model or power setting; selecting Max cannot replay a Medium recording.

To replay the video above, select **Second** tier and **Medium** power, then click **Start** below
Battleground. The video uses the saved `launch-2` session. Append
`?tier=second&effort=medium&broadcast=launch-2` to the local URL to keep replaying that exact session
even after newer fights are added.

## The five rounds

| Round | What happens | Referee |
| --- | --- | --- |
| **The Ring** | Fighters discover a hidden floor, shove rivals and compete for the center. | Simultaneous moves, knockdowns, center bounties and rope slams. |
| **Mirror** | Solve a hidden grid rule, then stack a valid transformation onto the rival's next puzzle. | A bounded solver checks that each attack leaves one possible answer. |
| **Buzzer** | Buzz with an answer or wait for another clue. A wrong buzz locks that player out. | Seeded math problems with computed answers and clue-dependent scores. |
| **Bot Brawl** | Write a light-cycle bot, inspect its losses and patch it between bouts. | QuickJS in WebAssembly with memory and execution limits; no host file or network access. |
| **Bluff** | Answer privately, then bet, call, raise or fold. Confidence meets a checked truth card. | Deterministic chip accounting and answers computed or read from fixed tables. |

The full broadcast runs Ring → Mirror → Buzzer → Bot Brawl → Bluff, with alternating sides,
round cards and a final score. The latest-recordings selection can combine recording sessions;
a named broadcast contains exactly one saved round per game at the same models and effort. Each record
keeps its models, effort, seed, limits and results. Captions describe submitted actions and engine
results; they are generated by the viewer, not quotations of a model's internal reasoning.
Scripted demos use authored actions and captions. Current recorder prompts request final game
outputs only, and streamed reasoning is neither collected nor displayed.

## Record a fight

Install the official [Claude Code](https://code.claude.com/docs/en/setup) and
[Codex CLI](https://developers.openai.com/codex/cli/) and sign into subscription accounts:

```bash
claude auth login
codex login
```

Start with the third tier at low effort. These are the recorder defaults, made explicit below:

```bash
pnpm fight:ring --tier third --effort low
pnpm fight:mirror --tier third --effort low
pnpm fight:buzzer --tier third --effort low
pnpm fight:brawl --tier third --effort low
pnpm fight:bluff --tier third --effort low
```

The runner checks subscription login and rejects API-key login. Model access and usage limits still
depend on each account. These commands consume your subscriptions' allowances; check provider
settings for any enabled extra usage. The project does not purchase credits or enable billing.
Models and effort mappings live in [`src/arena/corners.ts`](src/arena/corners.ts); an unavailable
model is a failed call, not an automatic switch to a different tier.

| Option | Purpose |
| --- | --- |
| `--tier third\|second\|frontier` | Select the same model tier for both corners. |
| `--effort low\|medium\|high\|extra\|max\|ultra` | Select shared effort or a mapped competition preset. |
| `--broadcast <name>` | Group five rounds into one fixed broadcast, such as `launch-1`. |
| `--seed <integer>` | Reproduce the challenge draw for Mirror, Buzzer, Bot Brawl and Bluff; model responses may still differ. |
| `--left claude\|gpt` | Choose the opening left corner in Mirror, Buzzer, Bot Brawl and Bluff. Ring uses `--opener` instead. |
| `--clock <seconds>` | Set the deadline for a decision (at least 5 seconds). |
| `--round-minutes <minutes>` | Set the whole-round deadline. |

Both corners share the same limits. Invalid replies get at most one retry; missed deadlines use
the round's declared fallback (hold, wait, pass or fold). Ctrl-C stops the run without saving an
incomplete record. Saves go to `src/games/<round>/fights/` with a new filename. Review any new model
output before committing it: record contents become public when you publish the repository.

Ring uses a selected floor rather than a seed and accepts `--opener claude|gpt`. Without a left
corner or opener override, each recorder alternates from its last saved fight. Ring also accepts `--rules classic` and `--floor cage` for historical comparisons. Its default
Crossroads floor gives the center four safe approaches; contact scoring rewards shoves and punishes
camping. Stored floor/rule versions preserve older matches.

## Two launch broadcasts

The second-tier pairing is Claude Sonnet 5.5 against GPT-6.1 Terra. Check both subscriptions'
remaining allowance and extra-usage settings before recording. These two broadcasts use medium
effort, the same game seeds, alternating corners through each broadcast, and reversed opening
corners for the rematch. Seeds reproduce challenges, not model
responses. The Ring uses its fixed Crossroads floor in both broadcasts.

```bash
pnpm fight:ring --tier second --effort medium --broadcast launch-1 --opener claude
pnpm fight:mirror --tier second --effort medium --broadcast launch-1 --seed 20261028 --left gpt
pnpm fight:buzzer --tier second --effort medium --broadcast launch-1 --seed 20261028 --left claude
pnpm fight:brawl --tier second --effort medium --broadcast launch-1 --seed 20261028 --left gpt
pnpm fight:bluff --tier second --effort medium --broadcast launch-1 --seed 20261028 --left claude

pnpm fight:ring --tier second --effort medium --broadcast launch-2 --opener gpt
pnpm fight:mirror --tier second --effort medium --broadcast launch-2 --seed 20261028 --left claude
pnpm fight:buzzer --tier second --effort medium --broadcast launch-2 --seed 20261028 --left gpt
pnpm fight:brawl --tier second --effort medium --broadcast launch-2 --seed 20261028 --left claude
pnpm fight:bluff --tier second --effort medium --broadcast launch-2 --seed 20261028 --left gpt
```

Run each command only after the previous one succeeds. A named round retries a provider failure
once within the available shot clock and call budget, then stops without saving. A provider refusal
stops immediately without a retry. Invalid model
moves and late replies still receive the normal game rulings. The recorder prints those rulings
and refuses to save a named round if either corner never made a usable decision. Existing rounds
in a broadcast cannot be overwritten, and model/effort changes cannot be mixed into its remaining
rounds. Retry an interrupted, unsaved round with the same command.

Named records use `src/games/<round>/fights/broadcast-<name>-<round>.json`. Review all ten records,
including model IDs, rulings, generated code and final scores. Render their local voices and build
the viewer. A named broadcast requires all five compatible rounds and never borrows a round from
another recording session.

The default call caps total 122 calls per provider per broadcast, or at most 488 calls across both
providers for two broadcasts. Actual use depends on game length and retries. The five round
deadlines total 160 minutes per broadcast; these are bounds, not an expected recording duration.
The local Bot Brawl sandbox can delay its deadline check during a synchronous engine operation.

Once the records, voices and build are ready, open `http://127.0.0.1:4173/` and select the tier and power
above Battleground. The existing Start button plays all five rounds. A specific saved session can
still be opened with `?tier=second&effort=medium&broadcast=launch-1` or `broadcast=launch-2`.
Opening a link never starts playback itself; a missing matching round keeps Start disabled. The
included second-tier launch recordings use Medium power. Other power selections need their own
matching recordings before they can play.

Put Chrome in full screen and hide its toolbar using **View → Always Show Toolbar in Full Screen**.
Open **Cmd+Shift+5**, enable system audio, leave the microphone off, and start the screen recording.
Then click **Start** below Battleground once. The Ring, Mirror, Buzzer, Bot Brawl and Bluff play in order
without another click. The final score and all five round results stay on screen until Watch again
or Done is chosen, so stop the Mac recording while that result card is visible.

Make a short test recording first and check its picture and audio. Keep provider account pages,
terminal output and notifications outside the capture. Playback uses saved moves and local audio;
it does not call the models again. These are experimental game matches; retain that description
and disclose synthetic commentary when sharing the video.

## Commentary and voices

Bundled MP3s play offline. Their text is derived from referee events, or authored for demos.
To optionally rewrite a Ring fight's commentary through a signed-in CLI:

```bash
pnpm commentate --fight src/games/ring/fights/<id>.json
```

Review the generated lines before rendering. `pnpm voices` renders locally using Piper and ffmpeg,
skips existing matching files, and removes MP3s no longer referenced by any fight or demo. Keep
unrelated recordings outside `public/voice`.

Use `pnpm voices --keep-unused` to render new narration while preserving every existing MP3.
This is useful when reviewing changes to historical commentary; unreferenced audio is not played
by the viewer but still needs review before publishing the repository or a static build.

Rendering requires `uv`, `ffmpeg`, and these local voice files:

```bash
uv venv tmp/piper-venv --python 3.12
VIRTUAL_ENV=tmp/piper-venv uv pip install piper-tts==1.8.0
for voice in en/en_US/bryce/medium/en_US-bryce-medium en/en_GB/cori/high/en_GB-cori-high; do
  name=$(basename "$voice")
  mkdir -p "tmp/voices/$name"
  for ext in onnx onnx.json; do
    curl --fail --location --output "tmp/voices/$name/$name.$ext" \
      "https://huggingface.co/rhasspy/piper-voices/resolve/5041a7a49ae5b3a0f30e6837769eb03fdbb231bd/$voice.$ext"
  done
done
pnpm voices
```

`BOI_PIPER_BIN` and `BOI_VOICES_DIR` override the local tools and voice location. On macOS, an overly
long Piper installation path can cause `phontab: No such file`; use a shorter installation path.
Voice provenance and dependency licenses are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Development

```bash
pnpm check
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

Tests use deterministic engines and fake CLI responses; they do not invoke paid models.
The production output is a static site in `dist/`; only that directory is needed for hosting.
There is no deployed model-execution API. Local fight recording remains an operator command.

For a nested hosting path, build with `pnpm build --base=/battle-of-intelligence/`. Keep the
whole `dist/` folder, including `licenses/`, workers, WebAssembly and `voice/`. Serve HTML with
revalidation (`Cache-Control: no-cache`); fingerprinted assets can be cached long term.

The viewer targets current desktop and mobile browsers with WebAssembly and module workers.
Narration has visible captions; each round has pause, restart and mute controls. The full fight
can be stopped with its close button or Escape. Reduced-motion preferences reduce animations,
and playback continues with captions when browser audio is unavailable.

See [CONTRIBUTING.md](CONTRIBUTING.md) for checks and review expectations,
[docs/architecture.md](docs/architecture.md) for the code map, and
[SECURITY.md](SECURITY.md) for the trust boundaries and vulnerability reporting route.
The [release readiness review](docs/release-readiness.md) records the latest checks and remaining limits.
Forge's original design remains in [docs/games/forge.md](docs/games/forge.md); its solver supports
Mirror, while the standalone live Forge round has been retired.
